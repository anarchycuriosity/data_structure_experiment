# 二叉树与树/森林 —— 算法实现总结

## 概述

本项目实现了二叉树的存储转换、亲属关系查找、最低公共祖先(LCA)、根到叶子的路径输出，以及普通树/森林的孩子兄弟表示法转换、最大度计算和括号表示法输出。所有操作均从数据文件读取树结构。

---

## 数据结构

### 二叉树节点 (bnode)
```cpp
struct bnode {
    elemen_type data;    // 节点数据(字符)
    bnode *lchild;       // 左孩子指针
    bnode *rchild;       // 右孩子指针
};
```

### 树的双亲表示 (p_tree)
```cpp
struct pt_node {
    char data;           // 节点数据
    int parent;          // 双亲下标(-1 表示根)
};
struct p_tree {
    pt_node node[MAX_LEN];
    int n;               // 节点数
};
```

### 孩子兄弟表示 (cs_node)
```cpp
struct cs_node {
    char data;
    cs_node *first_child;    // 第一个孩子
    cs_node *next_sibling;   // 下一个兄弟
};
```

## 测试用例详解

### test1 — 二叉树的顺序存储转换

**算法思路：** 利用层序遍历（BFS）将链式存储的二叉树转换为顺序数组。利用完全二叉树的下标规律：节点 `i` 的左孩子在 `2i`，右孩子在 `2i+1`。

**实现要点：**
- 使用 `std::queue` 进行层序遍历，队列元素为 `{节点指针, 下标}` 的 pair
- 空孩子位置填入 `#` 占位符
- 遍历过程中动态维护 `max_i`，记录数组的有效末尾

**数学原理：** 完全二叉树的顺序存储映射——对于下标从 1 开始的数组，第 `i` 个节点的左孩子下标为 `2i`，右孩子下标为 `2i+1`，父节点下标为 `i/2`。

---

### test2 — 查找目标节点的亲属关系

**算法思路：** 先将二叉树展开为顺序数组（复用 test1 的 s1_convert_array），然后利用顺序存储的下标数学关系直接定位亲属。

**查找逻辑：**
- **父节点：** `s1[i/2]`（i > 1 时存在）
- **左孩子：** `s1[2i]`（`2i <= NODE_NUM` 时存在）
- **右孩子：** `s1[2i+1]`
- **兄弟节点：** 若 `i` 为偶数则是左孩子，其右兄弟在 `s1[i+1]`；若 `i` 为奇数则是右孩子，其左兄弟在 `s1[i-1]`

**数学原理：** 完全二叉树下标公式的直接应用，将链式结构的亲属查找转化为 O(1) 的数组下标运算。

---

### test3 — 最低公共祖先 (LCA)

**算法思路：** 采用后序遍历递归。对于当前节点：
- 若当前节点为空，或等于目标节点 `l` 或 `r`，则直接返回当前节点
- 递归搜索左右子树
- 若左右子树各返回一个非空结果，说明当前节点就是 LCA
- 若只有一侧返回非空，则该侧的结果即为 LCA（说明两个目标都在同一子树中）

**数学原理：** 后序遍历保证了自底向上的处理顺序。该算法的本质是"在二叉树中查找两个节点，返回它们交汇的最深节点"。时间复杂度 O(n)，空间复杂度 O(h)（h 为树高，递归栈深度）。

---

### test4 — 输出根到叶子的所有路径

**算法思路：** 使用栈进行 DFS 回溯。用一个 `std::stack<elemen_type> path` 记录当前从根到当前节点的路径。

**核心逻辑：**
1. 访问节点时将其压入 `path`
2. 若当前节点是叶子（左右孩子均为空），则打印 `path` 中所有元素（即一条根到叶子的完整路径）
3. 递归处理左右孩子
4. 从递归返回后，将当前节点从 `path` 弹出（回溯）

**关键理解：** `path.pop()` 写在递归调用之后——这意味着从深层递归返回后，当前层的帧才会执行弹出，完成回溯。这正是递归"暂停-恢复"的精髓。

---

### test5 — 计算树/森林的最大度

**算法思路：** 树中某节点的度 = 其拥有的子树数量。在孩子兄弟表示法中，某节点的度 = 其 `first_child` 的兄弟链长度。

**实现：**
- `count_degree(cs_node* t)`：从 `t` 出发，沿着 `next_sibling` 链计数，得到兄弟个数
- `recurse(cs_node* t, int& max_degree)`：遍历整棵树，对每个节点调用 `count_degree(t->first_child)` 计算该节点的度，更新全局最大值

**流程：**
1. 从 `.tre` 文件以双亲表示法读取树/森林
2. 调用 `create_cs_tree` 将双亲表示转化为孩子兄弟表示
3. 递归遍历孩子兄弟树，计算每个节点的度
4. 取最大值

---

### test6 — 括号表示法（广义表）输出

**算法思路：** 以类似广义表的形式输出树/森林的层次结构。格式如：`A(B(E,F),C,D)`，其中 A 是根，B/C/D 是其孩子，E/F 是 B 的孩子。

**核心递归逻辑：**
1. 打印当前节点数据
2. 若存在孩子（`first_child != nullptr`）：打印 `(`，递归处理孩子子树，打印 `)`
3. 若存在兄弟（`next_sibling != nullptr`）：打印 `,`，递归处理兄弟

**关键理解：** 括号的对称性——谁开了 `(` 就必须由谁闭合 `)`。这由递归的"进入-返回"对称性自然保证。

**森林处理：** 外层 while 循环遍历森林的每一棵树的根（通过 `t = t->next_sibling`），每棵树之间用逗号分隔。

## 总结

| 测试 | 算法主题 | 核心数据结构/方法 | 时间复杂度 |
|------|---------|------------------|-----------|
| test1 | 顺序存储转换 | 层序遍历 BFS + 顺序表 | O(n) |
| test2 | 亲属关系查找 | 顺序表下标运算 | O(n) 建表 + O(1) 查询 |
| test3 | 最低公共祖先 | 后序遍历递归 | O(n) |
| test4 | 根到叶子路径 | DFS + 栈回溯 | O(n) |
| test5 | 树的最大度 | 孩子兄弟链表 + 递归 | O(n) |
| test6 | 括号表示输出 | 孩子兄弟链表 + 递归 | O(n) |
