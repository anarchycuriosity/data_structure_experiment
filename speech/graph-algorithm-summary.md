# 图 —— 算法实现总结

## 概述

本项目实现了图的两种存储结构（邻接矩阵和邻接表）、DFS 路径查找、邻接点遍历、有根有向树判定、以及 DFS 生成树的构建。所有操作均从 `.grp` 数据文件读取图。

---

## 数据结构

### 邻接表表示 (createGrpAdjLinkedList.h)

```cpp
struct EdgeNode {
    int adjVer;          // 邻接顶点编号(从1开始)
    eInfoType eInfo;     // 边的信息(权值/1)
    EdgeNode* next;      // 下一条边
};

struct VertexNode {
    elementType data;        // 顶点数据(字符)
    EdgeNode* firstEdge;     // 第一条边
};

struct Graph {
    VertexNode VerList[100]; // 顶点数组(从1开始)
    int VerNum;              // 顶点数
    int ArcNum;              // 边数
    GraphKind gKind;         // 图类型(UDG/UDN/DG/DN)
};
```

### 邻接矩阵表示 (createGrpAdjMatrix.h)

```cpp
typedef int cellType;

struct Graph {
    elementType Data[100];        // 顶点数据(从1开始)
    cellType AdjMatrix[100][100]; // 邻接矩阵
    int VerNum;                   // 顶点数
    int ArcNum;                   // 边数
    GraphKind gKind;              // 图类型
};
```

### 图类型枚举

```cpp
enum GraphKind { UDG, UDN, DG, DN };
// UDG = 无向图, UDN = 无向网, DG = 有向图, DN = 有向网
```

## 测试用例详解

### graph_test1 — 图文件读取与创建验证

**算法思路：** 从 `.grp` 格式文件读取图数据（使用基于边顶点对的读取方式 `CreateGraphFromFile`），构建邻接表，并输出图的边数来验证图是否正确创建。

**数据文件格式：**
- 文件标识行：`Graph`
- 图类型：`UDG`/`UDN`/`DG`/`DN`
- 顶点行：空格分隔的顶点字符
- 边数据行：每行两个顶点字符（一个边），网图还有第三个权值

**关键细节：** 无向图每条边在数据文件中出现一次，但存储时边数 = 原始边数 / 2（因为无向图的每条边对应邻接表中的两个边节点）。

---

### graph_test2 — DFS 判断两点间是否存在路径

**算法思路：** 使用栈模拟 DFS（深度优先搜索），以邻接矩阵作为图存储结构。从起始顶点出发，沿着边深入搜索，用 `visited[]` 数组标记已访问节点。

**核心逻辑：**
1. 找到起始顶点 `start` 和目标顶点 `end` 对应的数组下标
2. 将 `start` 下标压入栈
3. 循环弹栈：若当前节点等于 `end`，返回 `true`；否则将其未访问的邻接点逐一压栈
4. 栈空仍未找到，返回 `false`

**为何必须使用 visited 数组：** 对于无向图（UDG），若无 visited 标记，当遇到 A-B-A 这样的回边时，搜索会无限循环——A 的邻接点有 B，B 的邻接点有 A，如此往复。

**算法复杂度：** 时间复杂度 O(V + E)，空间复杂度 O(V)。

---

### graph_test3 — 邻接表的 firstadj / nextadj 操作

**算法思路：** 实现两个图的基本操作：
- `firstadj(G, tar1)`：返回顶点 `tar1` 的第一个邻接点编号
- `nextadj(G, tar1, tar2)`：返回在 `tar1` 的邻接链表中，`tar2` 之后的下一个邻接点编号；若不存在则返回 -1

**实现要点：**
- `firstadj`：找到 `tar1` 对应的顶点节点，直接返回 `firstEdge->adjVer`
- `nextadj`：沿着 `tar1` 的边链表遍历，找到 `tar2` 对应的边节点，返回其 `next->adjVer`

**应用场景：** 这两个函数是图的遍历（DFS/BFS）在邻接表上的基本原语。通过 `firstadj` 获取起点，通过 `nextadj` 遍历后续邻接点。

---

### graph_test4 — 判断有根有向树

**算法思路：** 判定一个有向图是否为"有根有向树"需同时满足三个条件：

1. **根节点入度为 0：** 存在且仅存在一个节点，没有任何边指向它
2. **其他节点入度恰好为 1：** 每个非根节点有且仅有一个父节点
3. **从根出发可达所有节点：** 从根节点做 DFS，能访问到图中所有节点

**实现细节：**
- 遍历每个顶点的边链表，对所有指向的目标顶点执行 `in_degree[cur->adjVer]++`
- 检查入度条件：根入度 = 0，其余入度 = 1
- DFS 检查连通性：从根出发，递归标记所有可达节点
- 最后遍历 `visited[]` 数组，确认所有节点均被访问

**边界处理：** 在遍历边链表时使用 `while (cur != nullptr)` 而非硬编码 26 次循环——因为边链表可能提前终止，用魔数 26 会导致访问随机内存。

**算法复杂度：** 时间复杂度 O(V + E)，空间复杂度 O(V)。

---

### graph_test5 — DFS 生成树

**算法思路：** 对无向连通图进行 DFS 遍历，记录遍历过程中经过的边，这些边构成的子图就是 DFS 生成树。

**核心逻辑：**
1. 从顶点 1 开始 DFS
2. 在 DFS 过程中，若当前节点 `ind` 能到达一个未访问过的邻接点 `p->adjVer`，则将这条边记录在 `bt[ind][p->adjVer] = 1` 和 `bt[p->adjVer][ind] = 1`（无向边对称标记）
3. 递归继续搜索

**输出：** 最终打印 `bt[][]` 邻接矩阵，其中值为 1 的位置表示 DFS 生成树中包含的边。

**数学原理：** 图的生成树是包含图中所有顶点的一个极小连通子图，具有 n-1 条边（n 为顶点数）。DFS 生成树的边对应 DFS 搜索过程中"发现新顶点"的那些边（即树边），回边（指向已访问节点的边）不会被收入生成树。

## 两种存储结构的对比

| 特性 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间复杂度 | O(V²) | O(V + E) |
| 判断边是否存在 | O(1) | O(degree) |
| 遍历某顶点的所有邻接点 | O(V) | O(degree) |
| 适用场景 | 稠密图 | 稀疏图 |
| 本项目使用位置 | test2 (路径判断) | test1/3/4/5 |

| 测试 | 算法主题 | 核心数据结构 | 关键技术 |
